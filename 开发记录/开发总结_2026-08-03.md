## 三、架构演进全景

```
P0 前：GUI 回调 → engine.func(conn, ...) → conn.execute(SQL)      （引擎吃 conn）
P2 后：GUI 回调 → repo.get_xxx() → engine.pure_func(data) → repo.save_xxx(result)
       引擎 6 文件全部不接 conn，dict 进 dict 出；加密/SQL 全在 Repository 层
P3 后：+ AES-256 加密 + 登录认证 + RBAC 四角色 + 审计日志 + 输入校验
P4-B：服务端 FastAPI（复用 P3 AuthManager + Repository）+ React 前端（医师端 P0 先行）
       医师端 B-T1~B-T7+B-T10 → 管理端 B-T11~B-T13 → 患者端暂不开发
```

## 五、踩坑记录（今日实战沉淀）

| # | 坑 | 解决方案 |
|---|-----|---------|
| 1 | ttk.Label 不支持 `fg` 参数（TclError） | 用 tk.Label（项目已知坑，多次踩） |
| 2 | bat 文件 UTF-8/LF 在 cmd 下中文乱码 + 命令错位 | **GBK 编码 + CRLF 行尾** + .gitattributes 强制 `*.bat eol=crlf` |
| 3 | Microsoft Store 别名：`where python` 找到但执行报 "Python was not found" | 深依赖实测逐级探测（只接受能跑系统的 Python） |
| 4 | 浅探测误选 uv 3.13（无依赖）+ PYTHONPATH 骗过顶层依赖检查 | 依赖检查深导入 `cryptography.hazmat.primitives.ciphers` 触发绑定 |
| 5 | SQLite 跨线程：TestClient 请求线程 vs 主线程连接 | `check_same_thread=False`（SQLite serialized + WAL + busy_timeout 兜底） |
| 6 | FastAPI `Depends(lambda r: ...)` 参数被解析成 query（422 缺 r） | 改函数内 `_require(request, perm)` 调用 |
| 7 | HTTP header 不能含中文（测试"坏token"） | 测试数据改 ASCII |
| 8 | register_date NOT NULL 但 API 可空 | API 缺省默认今天（匹配 GUI） |
| 9 | 随访 CSV"空白导出"：headers 旧键名（followup_id）vs 数据键（fu_id） | 键名对齐 + 空数据提示（不生成只有表头的空文件） |
| 10 | followup_view 缺 `_logger`（P2 清 import 时被删，导出即 NameError） | 补 `from log import get_logger` + 定义 |
| 11 | 备份文件名秒级时间戳互相覆盖 / restore 惰性校验失效 | 毫秒级 `%f` / `SELECT 1` 真实打开验证 |
| 12 | main 权限遍历漏新 Tab（dashboard/adherence 未登录显示 normal） | 遍历补全 + 构造时调用 `_apply_permissions` |
