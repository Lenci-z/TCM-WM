# 中西医结合心血管康复方案包与数字化全程管理系统

面向心血管疾病患者的、以 **"中医证型 × 心血管危险分层"双轴模型** 驱动的结构化康复方案与数字化全程管理系统。第一版临床实施以 **冠心病血运重建术后（CAD_PCI）** 人群为切入。

> 需求依据：`中西医结合心血管康复系统设计方案_v0.2.md`（唯一需求来源）
> 技术路线：Python 3.11 + tkinter + SQLite 本地桌面工具

---

## 核心特性

| 特性 | 说明 |
|---|---|
| 双轴处方模型 | 6 证型（气虚血瘀/痰浊闭阻/气阴两虚/心血瘀阻/阳虚水泛/肝阳上亢） × 3 危险分层（低/中/高） → 18 格矩阵（A1–F3） |
| 危险分层判定 | LVEF、血运重建方式、运动试验、METs、心衰症状等 16 条阈值规则（高危7/中危4/低危5），满足任一即升级 |
| FITT-VP 全要素处方 | 每格模板含频次/强度（RPE+心率，按分层调 k 系数 0.40–0.70）/时间/类型/总量/进阶 + 八段锦级别 + 中医干预 + 随访间隔 |
| 八段锦分级 | L0 卧位简化3式 ~ L3+ 标准八式+重复，按证型与分层匹配 |
| 安全校验层 | 配伍禁忌（十八反十九畏）+ 妊娠禁忌 + 病种特异禁忌（穿刺点/DAPT），处方生成时硬校验 |
| 三级预警 | 红（24h处置）/黄（72h）/蓝（仅患者端）共 16 条预警规则 |
| 规则全配置化 | 分层阈值/证型特征/处方模板/八段锦/预警/禁忌全部存表，GUI 可视化可调，零硬编码 |
| 多病种架构 | 全表含 `disease_category` 字段 + `disease_config` 参数集表；当前仅启用 CAD_PCI，其余 6 病种预留 |
| 医师审核签发 | 处方必经医师审核，不可跳过（临床决策支持工具定位） |
| 处方 PDF 导出 | reportlab 导出中文处方单 |
| 隐私保护 | 姓名、联系方式 MVP 标准库可逆加密存储 |

## 技术栈

- **Python 3.11** + **tkinter**（GUI，标准库）+ **SQLite**（存储，标准库）
- reportlab ≥ 4.0（处方单 PDF 导出，中文字体 msyh/simhei）
- 无 Web 框架，纯本地桌面工具

## 快速开始

```bash
# 1. 安装依赖（Python 3.11）
pip install -r requirements.txt

# 2. 启动（首次启动自动建库 + 导入种子数据）
python app/ui/main.py
```

主窗口为 5 Tab：患者管理 / 评估录入 / 处方管理 / 随访管理 / 规则库维护。

## 运行测试

```bash
python -m pytest test/ -v        # 引擎回归 + e2e + GUI 冒烟，0 FAIL 硬门槛
```

## 架构设计

三层结构，规则引擎为 ★核心IP★：

```
┌─────────────────────────────────────────────┐
│  UI 层（tkinter 5 Tab，全中文）               │
└────────────────────┬────────────────────────┘
                     ▼
┌─────────────────────────────────────────────┐
│  规则引擎（读库执行，规则外置不硬编码）         │
│  分层判定 → 证型判定 → 矩阵编码 → 处方生成     │
│  → 安全校验 → 预警引擎 → PDF 导出             │
└────────────────────┬────────────────────────┘
                     ▼
┌─────────────────────────────────────────────┐
│  数据层：12 业务表 + 5 规则表 + 病种参数集     │
│  （全表含 disease_category，多病种扩展）       │
└─────────────────────────────────────────────┘
```

- **规则外置**：分层阈值、证型特征、处方模板、八段锦分级、预警、禁忌全部配置化存表，可通过"规则库维护"界面可视化调整，不藏在代码里。
- **多病种设计**：数据模型按多病种规划，`disease_config` 已建 7 个病种条目；第一版仅启用 `CAD_PCI`，后续病种启用无需改表结构。
