## 2. 数据模型（17 表）

### 2.1 业务表（12 张，全部含 `disease_category` 字段——多病种架构）

| 表 | 说明 | 关键字段 |
|---|---|---|
| `disease_config` | 病种参数集（★v0.2 核心） | 分层阈值/运动禁忌/八段锦起始映射/随访模板/特有预警（JSON） |
| `patient` | 患者主表 | 姓名/联系方式加密存储（XOR+base64，正式版对接医院方案） |
| `procedure` | 手术/事件信息 | 类型/支架数/完全血运重建/切口类型/抗凝状态 |
| `assessment` | 评估记录 | 代谢全套（LDL-C/HbA1c/尿酸/eGFR/UACR）+ 心功能/运动/心理/行为 |
| `tcm_pattern` | 证型记录 | 主证/兼证/四诊JSON/舌象图/判定方式/医师确认 |
| `risk_stratification` | 危险分层 | 低/中/高 + 触发条件JSON + 参数集版本 + 医师确认 |
| `prescription` | 康复处方 | 矩阵编码/八段锦级别/有氧/抗阻/中医/营养/危险因素目标/签名/状态 |
| `adherence_log` | 打卡记录 | 任务类型/完成/时长/RPE/症状 |
| `vital_upload` | 自测数据 | 血压/心率/体重/步数等 |
| `alert` | 预警记录 | 红/黄/蓝 + 处置闭环（待处置→已关闭全程留痕） |
| `follow_up` | 随访计划与记录 | 1周/1月/3月/6月/12月 + 复评记录JSON |
| `clinical_event` | 临床事件 | 死亡/再入院/再次血运重建/心梗/卒中/出血 |

### 2.2 规则层表（5 张，★核心IP★ 规则外置）

| 表 | 内容 |
|---|---|
| `rule_tcm_pattern` | 6 证型特征（症状/舌象/脉象/关键词，供判定引擎匹配） |
| `rule_rx_template` | 双轴矩阵 18 格处方模板（FITT-VP 全要素 JSON） |
| `rule_baduanjin` | 八段锦 L0–L3+ 分级（体位/招式/估算METs/适用） |
| `rule_alert` | 预警规则（条件/适用范围/处置动作 JSON） |
| `rule_contraindication` | 禁忌规则（病种/证型/分层 * 通配） |

> 注：危险分层阈值、病种特异禁忌、八段锦起始映射、随访节点模板存于 `disease_config` 参数集 JSON（文档 3.3 定义），规则引擎统一从参数集加载，避免双源不一致。

## 3. 规则库内容（CAD_PCI 第一版）

| 规则 | 数量 | 说明 |
|---|---|---|
| 危险分层阈值 | 高7/中4/低5 | 满足任一即达本级，按 高危→中危→低危 判定；缺数据保守判高危 |
| 证型特征 | 6 证型 | 四诊勾选 → 关键词命中计数 → 主证+兼证 |
| 处方模板 | 18 格（A1–F3） | II 期基线；I/III 期引擎阶段适配；强度按分层（k 0.4–0.7） |
| 八段锦分级 | 5 级（L0–L3+） | 起始映射：高危L0/中危L1/低危L2；升降级条件 |
| 预警规则 | 16 条 | 红7（24h处置）/黄7（72h）/蓝2（仅患者端） |
| 禁忌规则 | 10 条 | 通用+证型级（肝阳上亢禁抗阻等）；CAD_PCI 病种特异 3 条（穿刺点/DAPT） |
| 随访模板 | 5 节点 | 手术日+7/30/90/180/365 天，必查项+选查项 |

## 4. 引擎执行流程（文档 3.4）

```
[数据输入]
  ↓
[病种识别] → 加载 disease_config 参数集
  ↓
[分层判定] ← 危险分层阈值（病种特异）
  ↓ ← 证型判定（四诊问卷 → 关键词匹配）
[矩阵编码 CAD_PCI-A2]
  ↓
[处方生成] ← 处方模板库 + 阶段适配（I/II/III）+ 心率区间（HRR k 法）
  ↓
[安全校验] ← 通用禁忌 + 病种特异禁忌（命中自动禁用抗阻等）
  ↓
[医师审核签发] ★人工确认必经环节，不可跳过★
  ↓
[打印 PDF]（reportlab 五大处方整合输出）
  ↓
[执行数据回流] → [预警引擎] → 进阶/降级判定 → 回到处方生成
```

## 6. 关键技术要点

1. **多病种架构**（v0.2 硬约束）：所有表带 `disease_category`，第一版仅启用 CAD_PCI，其余 6 病种建条目不启用；扩展只需填规则表，不改代码
2. **规则外置**：全部规则存表/JSON，GUI 规则库维护界面可视化编辑，保存即时生效（引擎读库）
3. **无 CPET 处方路径**：主观强度主导（RPE/谈话试验）+ 客观校验（HRR），服 β 阻滞剂时心率粗略上限 静息+20~30，以 RPE 为准
4. **6MWD 推算 METs**：peak VO₂ ≈ 4.948 + 0.023×6MWD；METs = VO₂/3.5（文献默认系数，**需本院数据校准——校准系数是技术秘密**）
5. **加密**：姓名/联系方式 XOR+base64 可逆加密（MVP），正式版对接医院加密方案
6. **合规设计**：医师审核签发不可跳过，系统定位"临床决策支持工具"，规避 SaMD 医疗器械注册问题

## 7. 待团队确认事项（文档第六章摘要）

- 本院 PCI 术后实际证型分布（决定矩阵主力格）
- 危险分层阈值采用 AACVPR 标准或本院修订
- 各证型对应院内制剂（冠心平、抗栓I号等）
- 预警阈值具体取值（科室共识 + 伦理认可）
- 八段锦各级别招式取舍与实测能耗（本院数据 = 核心技术秘密）
- 专利 FTO 检索、权属双备案（学校科技处 + 医院科教处）
