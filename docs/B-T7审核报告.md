## 3. 安全设计审查（本次重点）

规则库是**唯一允许直接改引擎数据源**的界面，安全要求最高。审查结果：

| 安全点 | 实现 | 结论 |
|--------|------|------|
| 表白名单 | `_check_table`：仅 RULE_TYPES 中 5 张表可写 | ✅ 防任意表 SQL 注入 |
| 字段白名单 | plain/json 均校验 `cfg["plain_fields"]` / `json_fields` | ✅ 防任意字段注入 |
| JSON 语法校验 | 保存前 `json.loads`，非法拒绝 | ✅ 防脏数据入库 |
| 权限 | `rules:edit` 仅管理员，前端导航同步隐藏 | ✅ 双保险（后端强校验 + 前端 UX） |
| 过滤器 | 危险分层阈值带 `filter='CAD_PCI'` | ✅ 与 tkinter 行为一致 |

> **评价**：这是 7 个 B-T 任务里安全设计最严谨的一个——规则库直接喂给引擎，白名单防注入是必须的，实现到位。
