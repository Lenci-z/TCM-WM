### 技术要点备忘
- 项目架构：Python 3.13 + tkinter + SQLite 本地桌面应用
- 核心模型：中医证型(6) × 心血管危险分层(3) = 18格矩阵(A1-F3)
- 多病种架构：disease_category 字段 + disease_config JSON 参数集（v0.2: 架构宽、数据窄，仅CAD_PCI启用）
- 无CPET处方路径：RPE(Borg 6-20) 主导 + HRR(心率储备) 客观校验
- 加密方案：XOR+base64 可逆加密（MVP级，正式版须升级）
