# 项目记忆 — 中西医结合心血管康复方案包与数字化全程管理系统

## 项目定位
中西医结合心血管康复方案包 + 数字化全程管理系统。Python 3.13 + tkinter + SQLite 本地桌面应用。

## 技术架构
- **核心模型**：中医证型(6) × 心血管危险分层(3) = 18格矩阵(A1-F3)
- **多病种架构**：disease_category 字段 + disease_config JSON 参数集（v0.2: 架构宽、数据窄，仅CAD_PCI启用）
- **规则外置**：5张规则表 + disease_config，引擎统一读库，不硬编码
- **无CPET处方路径**：RPE(Borg 6-20) 主导 + HRR(心率储备) 客观校验
- **医师签发不可跳过**：合规设计，临床决策"支持"工具定位
- **加密**：XOR+base64 可逆加密（MVP级，正式版须升级）

## 代码规模
15个.py文件，2487行。引擎层612行(6文件) + GUI层1071行(6文件) + DB层443行 + 测试361行。
