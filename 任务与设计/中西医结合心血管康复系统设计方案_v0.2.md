## 一、产品定位与知识产权策略

### 1.1 一句话定位

**一套面向心血管疾病患者的、以"中医证型 × 心血管危险分层"双轴模型驱动的结构化康复方案与数字化全程管理系统；第一版临床实施以冠心病血运重建术后人群为切入。**

### 1.2 为什么这个定位能形成知识产权

市面上已有的心脏康复系统绝大多数是**西医单轴**的：危险分层 → 运动处方 → 随访。中医院的做法通常是**两套系统并行**：西医给康复方案，中医给辨证用药，两者互不咬合。

本方案的独创性在于：**把中医证型作为第二个分层轴，与心血管危险分层交叉，形成矩阵化的处方生成规则。**这是可被权利要求覆盖的技术特征，也是任何西医心脏康复系统无法覆盖的空白。

### 1.3 核心策略：名字宽、IP宽、架构宽，入组窄

> **这是 v0.2 最重要的调整，务必贯彻到每一份对外文件。**

**权利要求的保护范围**与**说明书的实施例**是两回事；同样，**系统能力**与**第一版入组标准**也是两回事。分离处理带来的好处是双向的：对外（专利、转化谈判）覆盖面最大化，对内（科室、入组）阻力最小化。

| 层级 | 采用范围 | 具体表述 |
|---|---|---|
| 项目 / 中心名称 | **宽** | 心血管疾病康复管理中心 |
| 门诊名称 | **宽** | 心脏康复门诊 |
| 系统名称 | **宽** | 心血管康复全程管理系统 |
| 专利权利要求 | **宽** | 一种心血管疾病康复处方生成方法及系统 |
| 软著与数据模型 | **宽** | 架构支持多病种配置，预留扩展位 |
| 说明书优选实施例 | 窄 + 列举 | 以 PCI 术后为详细实施例，并列举其他适用场景 |
| **第一版入组标准** | **窄** | **限定 PCI / CABG 术后** |
| 第一个课题题目 | 窄 | 冠心病血运重建术后…… |

**原则：名字与IP决定天花板，入组标准决定今年能不能跑通。入组标准随时可改（一版 SOP 的事），名字与专利改起来代价极高。**

### 1.4 第一版为什么仍以 PCI 术后切入

虽然范围写宽，但临床实施必须先窄，理由有四：

1. **有明确的时间零点**——手术日即 Day 0，随访节点、康复分期、达标率全部可对齐。高血压、心衰等人群缺乏统一零点，队列离散，指标难以计算
2. **循证强度最高**——心脏康复的 I 类推荐与最高级别证据绝大部分来自冠心病血运重建后人群
3. **患者动机处于峰值**——术后早期恐惧感与依从性最高，是入组率最高的窗口
4. **产能约束**——本院年 PCI 约 700 例（≈13–14 例/周），叠加 II 期 36 次/3 个月的标准剂量，单个半天门诊很快饱和。**当前瓶颈是产能而非客源**

### 1.5 分阶段人群扩展路线

> **扩展顺序的设计原则：避开科内已有方向，优先选择零冲突的相邻人群。**

| 阶段 | 时间 | 纳入人群 | 说明 |
|---|---|---|---|
| **第一圈** | 0–18 月 | PCI 术后 → 扩至 CABG 术后、稳定性冠心病药物治疗患者 | 同病种、同指南、同康复逻辑，扩展成本近乎为零，科内无争议 |
| **第二圈** | 18–30 月 | 瓣膜置换/修复术后、起搏器/ICD 植入术后 | 需与心外科、心律失常组**合作**（提供康复模块，成果共享），可同步产出 MDT 与多学科协作成果 |
| **第三圈** | 30 月后 | 慢性心衰稳定期 | **必须以联合方式进入**——科内已有益气温阳方向及强心合剂、心衰I号等制剂，应主动寻求联合而非独立开展 |
| **不单列** | — | 高血压 | **永远不作为独立入组病种**，仅作为合并危险因素在所有人群中管理（科内已有国家级重点研究室方向，须严格规避） |

### 1.6 代谢维度的处理

"代谢"不作为独立人群维度，而是**贯穿全人群的横向管理维度**。

即：不设"代谢异常的心血管患者"这一入组标准，而是**所有入组患者一律纳入代谢指标管理**——血脂、血糖、体重/腰围、尿酸、肝脏脂肪变。这些指标在心血管人群中患病率极高，作为达标终点全套纳入。

> **这样处理有两个好处**：无需为代谢单独设入组条件；且天然区别于纯粹的心脏康复产品，构成本方案的**第三个差异化点**（前两个为双轴分层模型与分级传统功法处方）。

### 1.7 知识产权组合

| 类型 | 标的 | 优先级 |
|---|---|---|
| 发明专利 | 基于中医证型与危险分层的**心血管疾病**康复处方生成方法 | 高 |
| 软件著作权 | 康复管理系统源代码 | 高（最快，1–2月可下证） |
| 技术秘密 | 规则库参数、阈值表、证型判定权重 | 高（不公开，作为转化谈判筹码） |
| 著作权 | 患者教育手册、八段锦分级教学视频、SOP | 中 |
| 商标 | 系统名称与品牌 | 中 |
| 实用新型 | 若涉及硬件（如居家监测终端） | 低（后期） |

> **策略要点**：专利公开配方式规则，技术秘密保留具体参数。这样既有可主张的权利，又保留了不可复制的核心。

## 二、方案包（临床核心）

### 2.0 病种配置层（v0.2 新增）

在双轴模型之上，增设一个**病种配置层**。它不是第三个分层轴，而是一个**参数集选择器**——决定本次执行时调用哪一套分层阈值、禁忌规则和随访模板。

```
[病种配置层]  ← 决定调用哪套参数集
      ↓
[双轴分层模型]  证型 × 危险分层
      ↓
[处方生成]
```

**病种字典（disease_category）**

| 编码 | 病种 | 状态 | 启用阶段 |
|---|---|---|---|
| `CAD_PCI` | 冠心病 PCI 术后 | **规则库已填充** | 第一版 |
| `CAD_CABG` | 冠心病 CABG 术后 | 预留 | 第一圈 |
| `CAD_MED` | 稳定性冠心病（药物治疗） | 预留 | 第一圈 |
| `VALVE_POST` | 瓣膜术后 | 预留 | 第二圈 |
| `DEVICE_POST` | 起搏器/ICD 植入后 | 预留 | 第二圈 |
| `HF_STABLE` | 慢性心衰稳定期 | 预留 | 第三圈 |
| `PAD` | 外周动脉疾病 | 预留 | 备用 |

> **设计要点**：第一版**只填充 `CAD_PCI` 的规则内容**，其余病种在数据库和规则表中建立条目但置为未启用。这样系统架构、专利说明书、软著描述均覆盖全部病种，而实际运行只处理一个病种——**扩展时只需填规则表，不需改代码、不需重新申报**。

**病种相关的差异化参数**（各病种参数集需分别定义）

- 危险分层阈值的病种修正（如瓣膜术后需额外考虑抗凝状态与胸骨愈合）
- 运动禁忌与限制（如胸骨正中切口术后 8–12 周内限制上肢负重与扩胸动作）
- 八段锦起始级别的病种下调规则
- 随访节点密度
- 特有预警项（如 ICD 植入后的靶心率上限须低于室速识别频率）

### 2.1 双轴分层模型（核心创新点）

#### 轴一：心血管危险分层

参考 AACVPR 分层思路，结合本院数据简化为三级。**以下为 `CAD_PCI` 参数集**，其他病种启用时需另行定义：

| 分层 | 判定条件（满足任一即升级） |
|---|---|
| **低危** | LVEF ≥50%；完全血运重建；运动试验无缺血、无复杂室性心律失常；运动能力 ≥7 METs；无心衰症状 |
| **中危** | LVEF 40–49%；不完全血运重建但无残余缺血证据；运动能力 5–7 METs；中等强度下出现轻度症状 |
| **高危** | LVEF <40%；复杂室性心律失常；运动中出现心绞痛或 ST 压低 ≥1mm；运动中收缩压不升或下降；运动能力 <5 METs；心衰急性期；未完全血运重建且有残余缺血 |

#### 轴二：中医证型分层

PCI 术后常见证型（需团队根据本院实际证型分布调整权重）：

| 证型 | 主要特征 | 常见合并 |
|---|---|---|
| **气虚血瘀** | 胸闷隐痛、乏力气短、动则加重、舌暗有瘀斑、脉细涩 | 最常见，占比通常最高 |
| **痰浊闭阻** | 胸闷如窒、体胖、痰多、苔厚腻、脉滑 | 常合并代谢综合征 |
| **气阴两虚** | 心悸乏力、口干、五心烦热、舌红少苔、脉细数 | 常见于老年、糖尿病 |
| **心血瘀阻** | 胸痛固定、夜间加重、舌紫暗、脉涩 | 症状较重者 |
| **阳虚水泛** | 畏寒肢冷、下肢浮肿、气促、舌淡胖、脉沉细 | 合并心衰 |
| **肝阳上亢** | 头晕头痛、烦躁易怒、面红、脉弦 | 合并高血压 |

> **数据价值**：本院年 PCI 700 例，若能建立"术后证型分布 × 预后"的数据库，这本身就是极有价值的技术秘密和研究成果。

#### 双轴矩阵

```
                 低危          中危          高危
气虚血瘀      A1            A2            A3
痰浊闭阻      B1            B2            B3
气阴两虚      C1            C2            C3
心血瘀阻      D1            D2            D3
阳虚水泛      E1            E2            E3
肝阳上亢      F1            F2            F3
```

每个格子对应一套**参数化的处方模板**（运动强度、八段锦级别、中医干预、随访频次、预警阈值）。这就是系统的核心规则库。

### 2.3 运动处方生成规则（无 CPET 版本）

> **这一节是全套系统里技术含量最高、也最能形成专利权利要求的部分。**

#### 核心问题

CPET 是运动处方的金标准，但：本院暂无设备；PCI 术后患者绝大多数在服 β 受体阻滞剂，公式法推算最大心率严重失准；基层推广场景更不可能有 CPET。

**因此本系统采用「主观强度主导 + 客观指标校验」的双通道逻辑**——这既是现实约束下的解法，也恰恰是可推广性的来源。

#### 通道一：主观强度（主导）

**Borg RPE 量表（6–20 分制）**

| 康复阶段 | 目标 RPE | 对应体感 |
|---|---|---|
| I 期（住院） | 9–11 | 很轻松—轻松 |
| II 期初（1–4周） | 11–13 | 轻松—有点吃力 |
| II 期中后（5–12周） | 12–14 | 有点吃力 |
| III 期（维持） | 12–14，间歇可达 15 | 有点吃力—吃力 |

**谈话试验（Talk Test）作为交叉校验**
- 能完整说句子 = 强度偏低
- 能说话但需换气 = 目标区间 ✓
- 只能蹦字 = 强度过高，立即降级

#### 通道二：客观校验

**心率储备法（HRR）**，仅在以下条件下启用：
- 有实测最大心率（运动试验）→ 直接使用
- 无实测但**未服 β 受体阻滞剂** → HRmax = 220 − 年龄（低置信度）
- **服 β 受体阻滞剂** → 不使用公式，改用「静息心率 + 20–30 次/分」作为粗略上限，并以 RPE 为准

```
靶心率 = 静息心率 + k × (最大心率 − 静息心率)

k 取值：
  高危  0.40 – 0.50
  中危  0.50 – 0.60
  低危  0.60 – 0.70
```

**6MWT 推算运动能力**（用于分层，不用于直接定强度）

文献中有多个推算公式可选，例如：

```
peak VO₂ (mL/kg/min) ≈ 4.948 + 0.023 × 6MWD(m)
METs ≈ peak VO₂ / 3.5
```

> **注意**：不同人群推导的公式差异较大，本院应用前需用自有数据校准。这个校准过程本身就是一篇论文，也是技术秘密的一部分。

#### 处方输出结构（FITT-VP）

| 要素 | 内容 |
|---|---|
| **F** 频率 | 有氧 3–5 次/周；抗阻 2–3 次/周（非连续日）；柔韧 每日 |
| **I** 强度 | 由上述双通道确定，输出为 RPE 区间 + 心率区间 |
| **T** 时间 | 有氧：热身5分 + 主体 15→30→40分（递增）+ 整理5分 |
| **T** 类型 | 有氧（步行/踏车/八段锦）+ 抗阻（弹力带/自重）+ 柔韧 |
| **V** 总量 | 周总有氧时长目标：II期 90→150 分钟 |
| **P** 进阶 | 连续 2 周达标且无预警 → 强度或时长上调一档 |

#### 进阶与降级规则（系统自动判定）

**进阶条件（全部满足）**
- 连续 2 周完成率 ≥80%
- 平均 RPE ≤ 目标区间上限
- 无红色/黄色预警
- 无新发症状

**降级条件（满足任一）**
- 出现任何红色预警
- 连续 3 次 RPE ≥15
- 运动中或运动后出现胸痛、气促加重、头晕
- 静息心率较基线上升 >20%

### 2.4 八段锦分级处方（中医特色核心）

> 这是本系统区别于所有西医心脏康复产品的标志性模块，也是专利权利要求中"中医运动干预分级"的落点。

#### 分级设计

| 级别 | 体位 | 招式 | 估算强度 | 适用 |
|---|---|---|---|---|
| **L0** | 卧位/床边坐位 | 简化3式（双手托天理三焦、调理脾胃须单举、摇头摆尾去心火的上肢部分） | ~1.5–2 METs | I期，术后 1–3 天；高危 |
| **L1** | 坐位 | 完整八式坐位版，动作幅度减半 | ~2–2.5 METs | I期后段；高危/中危过渡 |
| **L2** | 站位 | 完整八式，低幅度，去除深蹲与大幅转体 | ~2.5–3 METs | II期，中危 |
| **L3** | 站位 | 标准完整八式 | ~3–4 METs | II期后段 / III期，低危 |
| **L3+** | 站位 | 标准八式 + 重复2遍 或 配合呼吸强化 | ~4 METs | III期维持，低危且耐受良好 |

> **强度数值需实测校准**：建议用便携式代谢分析仪或心率-METs 对照，在本院患者中实测各级别的实际能耗，形成本院自有数据。**这组数据是核心技术秘密，也是最有发表价值的原创发现之一。**

#### 分级切换规则

```
入组 → 按危险分层确定起始级别
  高危 → L0
  中危 → L1
  低危 → L2

升级条件：连续 1 周完成率≥80% + RPE≤13 + 无预警
降级条件：出现红色预警 或 连续 3 次 RPE≥15
```

#### 与有氧训练的配合

- I 期：八段锦为**主要**运动形式
- II 期：八段锦作为**热身与整理**（各 10 分钟）+ 有氧主体
- III 期：八段锦作为**居家维持**的核心，每日 1–2 次

### 2.8 预警规则（系统安全核心）

> 这是系统最重要的安全模块，也是软著中最有技术含量的部分之一。所有阈值须经科室审定。

#### 红色预警（立即中止运动 + 系统即时通知医师 + 电话联系）

- 静息或活动中胸痛发作
- 静息心率 >100 或 <50 次/分
- 收缩压 <90 mmHg 或 >180 mmHg
- 3 日内体重增加 >2 kg（提示心衰）
- 晕厥或先兆晕厥
- 新发气促、夜间不能平卧
- 连续 3 次上报 RPE ≥17

#### 黄色预警（系统提示 + 下次随访重点关注）

- LDL-C / 血压 / HbA1c 任一未达标
- 漏服抗血小板药 ≥2 次/周
- 连续 2 个随访周期未上传数据
- RPE 持续 14–16
- PHQ-9 ≥10 或 GAD-7 ≥10
- 运动完成率 <50%
- 体重较基线增加 >3%

#### 蓝色提示（依从性激励）

- 连续达标 → 推送鼓励与进阶
- 即将到期的随访 → 提前 3 天提醒

#### 预警处置闭环

```
触发 → 分级 → 通知对象 → 处置动作 → 记录 → 关闭
红色：即时推送医师端 + 短信/电话 → 24h内必须处置并记录
黄色：进入医师工作台待办 → 72h内处置
蓝色：仅患者端展示
```

**所有预警的触发、通知、处置、关闭全程留痕**——这既是医疗安全要求，也是系统的质控数据来源。

### 3.4 规则引擎设计（软著核心）

> **这是整个系统最有技术含量的部分，也是软著申报时应重点描述的独创性所在。**

#### 设计原则：规则外置

所有临床规则以**配置化的规则表**形式存储，而非硬编码。这样：
- 规则更新不需要改代码、不需要重新申报
- 不同医院可配置不同参数（利于推广授权）
- 规则表本身可作为技术秘密单独保护

#### 引擎执行流程

```
[数据输入]
    ↓
[病种识别] ★v0.2新增★ → 加载 disease_config 参数集
    ↓
[分层判定引擎]  ← 危险分层规则表（病种特异阈值）
    ↓          ← 证型判定规则表
[矩阵编码 CAD_PCI-A2]
    ↓
[处方生成引擎]  ← 处方模板库（按病种筛选）
    ↓
[安全校验层]   ← 通用禁忌规则表（如：肝阳上亢禁高强度抗阻）
    ↓          ← 病种特异禁忌表 ★v0.2新增★
               （如：胸骨正中切口术后8–12周限制上肢负重）
    ↓
[医师审核签发] ★人工确认为必经环节★
    ↓
[推送患者端]
    ↓
[执行数据回流] → [预警引擎] ← 预警规则表
                     ↓
              [进阶/降级判定] → 回到处方生成
```

> **关键设计**：医师审核签发为**不可跳过**的环节。系统只做建议，不做决策。这既是医疗安全要求，也是规避医疗器械注册问题的重要设计（详见 4.5）。

2. **依据所述病种类别标识，从参数集库中加载对应的分层阈值集与禁忌规则集** ★v0.2新增★
3. 依据第一规则集对临床指标进行心血管危险分层，得到第一分层结果
4. 依据第二规则集对四诊数据进行证型判定，得到第二分层结果
5. 将第一、第二分层结果映射为二维矩阵编码
6. 依据所述矩阵编码与病种类别标识，从处方模板库中调取对应模板
7. 结合患者的康复阶段与周次参数，生成包含运动处方、中医干预方案的结构化康复处方
8. 其中所述运动处方包含分级传统功法处方，所述分级依据危险分层、康复阶段与病种禁忌共同确定
9. 依据执行数据回流触发进阶或降级判定，动态更新所述结构化康复处方

> **第 2 项与第 6 项的病种参数化，是 v0.2 新增的技术特征**。它既扩大了保护范围，本身也是一个可主张的独立技术点——把"多病种适配"做成可配置的参数集，而非为每个病种写一套独立逻辑。

**说明书中应列举的适用场景**（用于支撑宽范围权利要求）：

- 冠心病经皮冠状动脉介入治疗后（**优选实施例，给出完整参数**）
- 冠状动脉旁路移植术后
- 稳定性冠心病药物治疗期
- 心脏瓣膜置换或修复术后
- 心脏起搏器、ICD、CRT 植入后
- 慢性心力衰竭稳定期
- 外周动脉疾病
- 心血管疾病高危人群的一级预防

> **可专利性的关键**：单纯的疾病诊断和治疗方法在中国不授予专利权（专利法第25条第1款第4项）。因此权利要求必须写成**"方法及系统"**，强调数据获取、参数集加载、规则映射、编码转换、自动化生成等**数据处理技术手段**，而非临床决策本身。这一点必须由专利代理人把关，建议选择有医疗信息化领域经验的代理所。

#### 专利二：分级功法处方方法

**建议名称**：一种基于运动耐量分层的传统功法康复训练分级处方方法及系统

围绕八段锦 L0–L3+ 分级、强度标定、升降级判定规则展开。**同样不限定病种**——传统功法分级处方的适用面本就远超冠心病，可延伸至心衰、慢阻肺、肿瘤康复、老年衰弱等场景，说明书中应一并列举。

#### 专利三：预警方法（可选）

**建议名称**：一种居家康复训练的多级安全预警方法及系统

围绕多源数据融合、病种特异阈值、分级触发、闭环处置流程展开。**不限定于心脏康复**，居家康复训练的安全预警是通用问题。

### 4.3 技术秘密（不申请，严格保密）

以下内容**不写进专利、不公开发表具体数值**：

- 各证型 × 危险分层的具体处方参数表
- 八段锦各级别的实测能耗数据
- 6MWT 推算公式的本院校准系数
- 预警阈值的具体取值
- 证型判定的四诊条目权重

> **策略**：专利公开"怎么做"的框架，技术秘密保留"具体是多少"。买方拿到专利授权也无法独立复现效果，必须连同技术秘密和培训一起买——这才是转化谈判中的定价基础。

### 4.4 著作权与商标

- **著作权**：八段锦分级教学视频、患者教育手册、SOP 操作规范、培训课件
- **商标**：系统名称与品牌标识，建议在第 9 类（软件）、第 42 类（技术服务）、第 44 类（医疗服务）注册

### 4.5 一个必须注意的合规问题

**是否构成医疗器械软件（SaMD）？**

国家药监局对独立软件的监管有明确界定。判断要点在于软件是否**直接给出诊断或治疗决策**：

- 若系统仅**辅助管理、记录、提醒、教育**，医师保留全部决策权 → 通常可按非医疗器械管理
- 若系统**自动输出诊断结论或直接决定治疗方案** → 可能需按二类医疗器械注册

**因此本设计中"医师审核签发为不可跳过环节"是一个刻意的合规设计**，不只是安全考虑。在申报和对外描述时，应一致地表述为"临床决策**支持**工具"，而非"决策工具"。

若未来要做商业化销售，建议提前咨询医疗器械注册的专业机构。

## 五、落地路径

### 5.1 MVP 范围（先做这些，其余全部砍掉）

**第一版只做三件事**：

1. **患者建档 + 结构化评估录入**（含证型判定问卷）
2. **处方生成 + 医师签发 + 打印**（先不做患者端）
3. **随访提醒 + 复评录入**

**暂不做**：可穿戴对接、复杂看板、多中心、AI 判读、社区端。

**为什么**：这三件事已经能支撑专病门诊运转、产出软著、积累数据。剩下的等有钱有需求了再说。

> **v0.2 的一条硬性开发要求**：即使第一版只跑 `CAD_PCI` 一个病种，**数据模型和规则表也必须按多病种设计**（`disease_category` 字段、`disease_config` 参数集表一开始就要有）。
>
> 这一条不能省。多病种架构在第一天做进去几乎零成本，事后补则要重构数据库、重做数据迁移，且软著和专利的描述与实际代码会出现不一致。**架构宽、数据窄，是本版的核心工程约束。**

### 5.2 开发资源

三种路径，按成本排序：

| 方式 | 成本 | 适用 |
|---|---|---|
| 低代码平台自建（如飞书多维表格、简道云） | 极低 | 验证流程，1–2 个月出原型 |
| 学校医工交叉研究院合作 | 低 | 有真实开发能力，可申报校级项目 |
| 外包开发 | 中高（10–50万） | 有横向经费或转化预付款后 |

> **强烈建议从第一种开始**。先用低代码把流程跑通半年，把规则表打磨扎实——**规则表才是IP，代码只是载体**。规则不成熟就去写代码，是最常见的浪费。

另外，学校与南京邮电大学共建的医工交叉研究院是现成的对接平台，值得主动联系。

### 5.3 与整体规划的衔接

```
回顾性研究（数据）
      ↓
专病门诊（场景）→ 方案包成型 → 规则表打磨
      ↓                          ↓
课题立项（经费）            专利 + 软著
      ↓                          ↓
临床验证数据 ─────────────→ 成果转化 / 横向课题
                                 ↓
                            转化收益（90%归完成人）
```

**方案包和系统不是新增的一件事，它是前面那套规划的自然产物。**门诊在运转，数据在积累，规则在打磨——把这些固化下来，就是知识产权。

## 附一：设计说明

本框架的独创性主张集中在四点，申报和谈判时应突出：

1. **双轴分层模型**——中医证型作为独立分层轴与心血管危险分层交叉，驱动处方生成
2. **分级传统功法处方**——八段锦按体位与幅度分级，与危险分层、康复阶段和病种禁忌动态匹配
3. **无 CPET 依赖的处方生成路径**——主观强度主导、客观指标校验的双通道逻辑，使方案可在无设备的基层场景推广
4. **代谢维度的横向贯穿**（v0.2 强化）——代谢指标不作为入组条件而作为全人群达标终点，区别于纯粹的心脏康复产品

第三点尤其重要：**它把"本院没有 CPET"这个约束，转化成了"可在资源受限场景推广"的产品优势**。这是转化谈判中最有说服力的卖点，因为基层市场远大于三甲市场。
