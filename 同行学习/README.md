# 同行学习 · 相似工程经验与可学习要点

> 本文件夹用于记录相似工程中看到的经验、踩坑、创意与可学习的要点。
> 凡是涉及「我没想到」「这个思路可以借鉴」「这种设计模式值得借鉴」类内容，归档于此。

## 用途

- 持续记录从其他项目、同行代码、开源实现、技术博客中观察到的可学习点
- 与自己正在进行的项目（翻译工具 / 翻译工具 / 医学英语 / 番茄钟等）形成对照
- 防止「踩过的坑」和「见过的优秀方案」随时间流失

## 归档结构

```
同行学习/
├── README.md          ← 本文件（索引+说明）
├── 工程/              ← 某个具体相似工程的完整记录
│   └── YYYY-MM-DD_工程名/
│       ├── 概览.md        ← 背景、目标、技术栈
│       ├── 经验.md        ← 通用经验（可迁移到自己的项目）
│       ├── 要点.md        ← 可学习的具体点子
│       └── 原文链接.md    ← 引用来源
├── 经验/              ← 跨工程的通用经验
│   └── 主题.md        ← 例如：分层架构、错误处理、测试策略
└── 索引.md            ← 一句话速查表
```

## 记录规则

每条记录至少包含：

1. **触发场景** — 什么情况下看到/想到的
2. **要点** — 核心可学习点（一句话）
3. **可迁移方向** — 在自己的哪个项目能用上
4. **来源** — 出处（链接/项目名/对话）
